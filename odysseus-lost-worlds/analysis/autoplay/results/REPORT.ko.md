# 자동 플레이 밸런스 보고서

[English](REPORT.md) · **한국어**

봇이 실제 게임 코드(v17 `game.js` 등, 수정 없음)를 **4,800판** 플레이했습니다: 난이도 4개 × 봇 실력 6단계 × 시드 200개. 한 판은 목숨 3개로 처음부터 끝까지 진행하며, 죽으면 페이지와 똑같이 게임의 "이어하기"로 재도전합니다. 목적은 실제 플레이어를 대신하는 것이 아니라 *어디가* 어려운지 보는 것입니다. 게임 코드: v17(커밋 `55539e0`). 같은 시드 240판을 v19(`14dfc20`)에서 다시 돌려 완전히 같은 결과가 나왔으므로, 이 숫자는 v19에도 그대로 맞습니다.

## 핵심 결과

- **숙련, 보통 봇은 모든 난이도에서 모든 판을 클리어했습니다.** 반응 약 0.3초에 보통 봇만큼 실수하는 플레이어라면, 어느 난이도도 판을 끝낼 만큼 어렵지 않습니다.
- **초보 봇** 클리어율: 이타카 (쉬움) 100%, 에게해 (보통) 100%, 시련 (어려움) 90%, 분노 (최상) 39%. 가장 낮은 곳은 분노 (최상): 39% (32%–45%).
- **실패한 판의 98%(227판 중 222판)가 처음 세 전투 스테이지**(G1 키클롭스 폐허, 폴리페모스, 포세이돈)에서 끝났습니다.
- **초보** 봇의 사망은 G1–G3에서 752번, 그 뒤 모든 스테이지를 합쳐 5번이었습니다. 플레이어는 스테이지마다 공격력 +8%, 보스마다 최대 HP +20을 얻기 때문에 같은 봇에게 후반이 더 쉬워집니다.
- **가장 위험한 보스:** 분노 (최상)의 초보 봇에게 포세이돈. 전투에 들어간 목숨의 64% (57%–70%)를 잃었습니다(227번 중 145번).
- **숙련 봇은 HP를 거의 잃지 않습니다** (이타카 (쉬움) / 에게해 (보통) / 시련 (어려움) / 분노 (최상)에서 한 판 전체 1 / 3 / 7 / 20 HP). 보스를 향해 S를 눌러 물폭탄·화살비까지 포함한 모든 보스 공격을 막고, 보스나 무리가 닿으면 곧바로 필살기를 쓰기 때문입니다.
- **전혀 피하지 않는 봇이 초보 봇보다 더 자주 클리어했습니다**: 시련 (어려움), 분노 (최상) (100% 대 90%, 60% 대 39%). 늦고 어설픈 회피와 헤매기보다 빨리 처치하고 흡혈하는 쪽이 더 안전한 것으로 보입니다.
- **보통 봇을 살리는 것은 방패보다 필살기입니다.** 분노 (최상)에서 보통 봇은 한 판에 387 HP를 잃는데, 필살기가 없으면 1279 HP(판당 사망 0.89), 방패가 없으면 460 HP를 잃습니다. 한 판에 필살기를 약 28번 썼습니다. 몇 초만 때려도 게이지가 차고, 한 번 쓸 때마다 모든 적이 2.7초 멈추고 플레이어는 무적이 되며 화살과 경고 원이 모두 사라집니다.
- 멈추거나 60분 게임 시간 제한에 걸린 판은 없었습니다.

## 봇 실력 단계

봇은 플레이어가 화면을 보듯 게임 상태를 읽고, 게임 키(방향키, A, S, Q/W/E/R, Enter)를 누르는 것으로만 행동합니다. 실력은 *보고 누르는 방식*만 바꾸며 게임 숫자는 건드리지 않습니다. 모든 봇은 기본 청동검을 쓰고 점프하지 않습니다. 아래 값은 실제 사람을 잰 것이 아니라 **가정**입니다.

| 설정 | 숙련 | 보통 | 초보 |
| --- | ---: | ---: | ---: |
| 새 공격에 대한 반응 | 180 ± 30 ms | 300 ± 50 ms | 500 ± 100 ms |
| 아예 못 본 공격 | 2% | 12% | 45% |
| 늦게 본 공격 | 5% (+100–250 ms) | 20% (+150–400 ms) | 30% (+200–500 ms) |
| 판정 범위 추정 오차 | +6 ± 3 px | +0 ± 6 px | -4 ± 8 px |

| 힐 존 | HP < 80%일 때 95% | HP < 50%일 때 60% | HP < 35%일 때 30% |

- **숙련**: 이 봇 설계로 낼 수 있는 최선에 가깝습니다. 막을 수 있는 공격은 거의 다 막고 필살기를 조준해서 씁니다.
- **보통**: 약 250–350ms에 반응하고, 일부 공격은 못 보거나 타이밍을 놓치며, 방패는 절반쯤 쓰고, 게이지가 차면 곧 필살기를 누릅니다.
- **초보**: 느리고, 공격의 절반 가까이를 못 보며, 방패를 거의 안 쓰고, 헤매고, 필살기를 늦게 아무렇게나 씁니다.

무엇이 중요한지 보려고 돌린 기준 봇(플레이어 모델 아님):
- **무방어 기준**: 초보와 같은 속도지만 걸어가서 공격만 합니다. 피하기·막기·힐 존 찾기를 전혀 하지 않습니다. 공격만으로 어디까지 가는지 보여 줍니다.
- **보통, 방패 없음**: S를 전혀 누르지 않는 보통 봇.
- **보통, 필살기 없음**: Q/W/E/R을 쓰지 않는 보통 봇. 단, 안티노오스를 끝내려고 게임이 요구하는 Q 한 번은 누릅니다.

## 7. 살펴볼 후보 (결정 아님)

숫자가 눈에 띄는 곳입니다. 사람과 함께 플레이 테스트로 확인할 질문이지 검증된 해결책이 아니며, 여기서 숫자 변경을 사실로 제안하지 않습니다.

2. **어려운 난이도의 포세이돈과 폴리페모스.** 초보 봇의 도전 1회당 사망률(이타카 (쉬움) / 에게해 (보통) / 시련 (어려움) / 분노 (최상)): 폴리페모스 0% / 1.0% / 27% / 48%; 포세이돈 0% / 3% / 31% / 64%; 조조 0% / 0% / 0% / 6%; 안티노오스 0% / 0% / 0% / 0%. 두 그리스 보스는 공격력·HP 성장 대부분이 오기 전에 나옵니다.
3. **방어 수단으로서의 필살기.** 한 판에 잃은 HP(이타카 (쉬움) / 에게해 (보통) / 시련 (어려움) / 분노 (최상)): 보통 봇 131 / 210 / 291 / 387, 필살기 없이 490 / 737 / 960 / 1279, 방패 없이 165 / 248 / 341 / 460. 보통 봇은 한 판에 필살기를 23 / 25 / 27 / 28번 썼습니다. 코드상 한 번 때리면 에너지 8(보스는 12), 처치하면 13, 콤보 세 번째 타격이면 10을 얻고, 필살기 한 번에 세상이 2.7초 멈추며 3초 무적이 되고 모든 투사체와 위험 지역이 사라집니다. 질문: 필살기가 이렇게 자주 나오고 이렇게 강하게 지켜 주는 것이 의도인가?

## 8. 이 결과로 알 수 있는 것과 없는 것

**알 수 있는 것:** *같은 봇* 기준으로 스테이지·보스·난이도를 서로 비교하기, 피해와 사망이 어디에 몰리는지, 난이도 한 단계가 결과를 얼마나 바꾸는지, 밸런스를 바꾼 뒤 똑같이 다시 재 보기(같은 시드는 같은 판을 만듭니다).

**알 수 없는 것:**
- **봇은 사람이 아닙니다.** 봇은 정해진 오차 안에서 모든 판정 범위를 정확히 알고, 화면에 헷갈리지 않고, 당황하지 않고, 배우지 않고, 지루해서 그만두지도 않습니다. 사람은 점프하고 무기를 바꾸기도 하지만 이 봇들은 그러지 않습니다.
- **실력 단계는 가정입니다.** 반응 시간과 실수 비율은 직접 정한 값이지 잰 값이 아닙니다. 똑같이 그럴듯한 다른 값을 고르면 클리어율이 크게 달라질 수 있습니다. 숫자는 "플레이어의 X%가 클리어한다"가 아니라 **상대 비교**(어느 스테이지가 더 어려운가)로 보세요.
- **아직 실제 플레이어 데이터로 확인하지 못했습니다.** 라이브 사이트는 페이지 뷰 약 110회에 끝까지 간 판이 없어 봇과 비교하기에 너무 적습니다.
- 화면은 그리지 않고(렌더링 없음), 게임은 초당 60스텝 고정으로 돌립니다. 게임 규칙은 그대로지만 브라우저에서는 화면 흔들림에도 난수를 쓰므로, 여기의 시드와 브라우저의 판은 일치하지 않습니다.
- 신뢰구간은 판마다의 무작위성만 반영하며, 봇 모델 자체의 불확실성은 반영하지 않습니다.

## 9. 실행 방법

게임 폴더(`odysseus-lost-worlds/odysseus-lost-worlds`) 안에서 Node.js 24 이상을 쓰세요. `npm install`은 필요 없습니다.

```sh
node analysis/autoplay/simulate.mjs                  # 전체 배치 (칸마다 시드 200개), results/ 다시 씀
node analysis/autoplay/simulate.mjs --runs 20        # 빠르게 보기
node analysis/autoplay/simulate.mjs --one wrath novice 7   # 한 판을 JSON으로
node analysis/autoplay/simulate.mjs --report-only    # summary.json으로 보고서만 다시 만들기
node --test analysis/autoplay/check.mjs              # 시뮬레이터 점검
```

다른 옵션: `--difficulties ithaca,wrath`, `--skills expert,novice`, `--seed 1000`(첫 시드), `--workers 4`, `--out 폴더`. 봇 실력 값은 `skills.mjs`, 봇 본체는 `bot.js`에 있습니다. 게임 숫자를 바꾼 뒤에는 배치를 다시 돌려 `summary.json`을 비교하세요.

# ODYSSEUS: LOST WORLDS · 게임 폴더

[English](README.md) · **한국어**

[프로젝트 소개](../README.ko.md) · [업데이트 내역](../CHANGELOG.ko.md)

트로이 전쟁을 마친 오디세우스가 고향 이타카로 돌아가는 여정을 그린 브라우저 액션 게임입니다. 방향키로 이동하며 적의 공격을 피하고, 무기와 신들의 힘을 사용해 11개 스테이지를 통과합니다. 그리스에서 시작해 낯선 동방 세계를 거쳐 이타카에 도착하는 이야기입니다.

**[게임 바로 플레이하기](https://odysseus-lost-worlds.sooyeon-jun-0389.chatgpt.site/)** · 공개 게임 **v16** · 이 폴더 **v17 (배포 전)**

## 어떤 게임인가요?

- 일반 적을 물리치고 길을 열어 다음 스테이지로 진행합니다.
- 폴리페모스, 포세이돈, 조조, 안티노오스와 보스전을 치릅니다. 보스마다 공격 방식이 다릅니다.
- 검·창·단검 중 무기를 바꿔 사용할 수 있고, 에너지가 모이면 신들의 필살기를 쓸 수 있습니다.
- 체력과 목숨을 관리하며 점수를 쌓습니다. 여정을 끝내면 공개 게임의 순위표에 기록을 남길 수 있습니다.
- 시작 전에 4가지 난이도 중 하나를 고릅니다. 현재 온라인 순위표는 난이도별로 나뉘지 않습니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| 방향키 | 이동 |
| A | 공격 |
| S 길게 누르기 | 방패로 방어 |
| Space | 점프 |
| 1 / 2 / 3 | 검 / 창 / 단검 선택 |
| Q / W / E | 아테나 / 아킬레우스 / 헤르메스 필살기 — 각각 1칸 소모 |
| R | 제우스 필살기 — 2칸 소모 |
| Esc | 일시정지 / 계속하기 |

## 버전

버전별 변경 사항(v13~v17)은 [업데이트 내역](../CHANGELOG.ko.md)에 있습니다. 공개 사이트는 v17을 별도로 배포하기 전까지 v16입니다.

선택형 플레이 기록은 v16에서 추가했습니다. 게임 시작 전에 동의한 경우에만 상세 행동을 기록하며, 동의하지 않아도 플레이할 수 있습니다. [수집 안내와 운영자 CSV 절차](TELEMETRY-v16.ko.md)를 참고하세요. 실제 원본 기록과 비밀값은 저장소에 포함하지 않습니다.

## 실행과 파일 구성

위의 공개 게임 주소에서 바로 플레이할 수 있습니다. 이 폴더를 내려받았다면 `index.html`을 브라우저에서 열어 게임 화면을 볼 수도 있습니다.

- `index.html`: 게임 화면과 조작 안내
- `*.js`: 이동, 전투, 화면 표시 등 게임 동작
- `assets/`: 게임에 쓰이는 이미지
- `server/`, `db/`, `drizzle/`: 서버 소스와 저장 구조
- `test-game.cjs`, `test-*.mjs`: 자동 검사

온라인 순위·조회수·플레이 기록은 공개 게임 주소의 서버와 데이터베이스에 연결된 기능입니다. `index.html`을 파일로 직접 열면 이 기능들은 제공되지 않습니다.

검사는 Node.js 24 이상에서 이 폴더로 이동해 `npm test`와 `node build.mjs`로 실행합니다.

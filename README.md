# ODYSSEUS: LOST WORLDS

**한국어** · [English](README.en.md)

트로이에서 이타카까지, 신들의 시련을 넘어 집으로 돌아가는 브라우저 액션 게임입니다.

**[게임 바로 플레이하기](https://odysseus-lost-worlds.sooyeon-jun-0389.chatgpt.site/)** · 공개 게임 **v16** · 저장소 **v17 (배포 전)**

## 게임 소개

플레이어는 트로이 전쟁을 마친 오디세우스가 되어 고향 이타카로 향합니다. 그리스에서 낯선 동방 세계를 거치는 11개 스테이지에서 적의 공격을 피하고, 무기를 바꾸고, 신들의 힘을 빌려 싸웁니다.

- **무기 3종:** 검, 창, 단검을 상황에 맞게 선택합니다.
- **필살기 4종:** 아테나, 아킬레우스, 헤르메스, 제우스의 힘을 사용합니다.
- **보스전:** 폴리페모스, 포세이돈, 조조, 안티노오스의 서로 다른 공격에 대응합니다.
- **생존:** 목숨 3개로 시작하며, 보스전 중 무작위로 나타나는 초록색 회복 구역 안에 서 있으면 체력이 회복됩니다.
- **점수와 순위:** 여정을 완료하면 공개 게임에서 닉네임으로 점수를 등록할 수 있습니다. 로그인은 필요하지 않습니다.

컴퓨터와 키보드로 플레이하는 게임입니다.

## 시작하기

1. 위의 게임 링크를 컴퓨터 브라우저에서 엽니다.
2. 난이도를 고른 뒤 게임을 시작합니다.
3. 방향키로 이동하고 `A`로 공격합니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| 방향키 | 이동 |
| A | 공격 |
| S 길게 누르기 | 방패로 방어 |
| Space | 점프 |
| 1 / 2 / 3 | 검 / 창 / 단검 선택 |
| Q / W / E | 아테나 / 아킬레우스 / 헤르메스 필살기 — 각각 1칸 소모 |
| R | 제우스 필살기 — 2칸 소모 |
| Esc | 일시정지 / 계속하기 |

공격·방어·필살기는 착지 후 사용합니다. 착지 직후에는 짧은 대기 시간이 있습니다.

## v17 업데이트 · 더 큰 게임 화면

- 일반 화면의 최대 너비 제한을 없애고, 조작 안내를 필요할 때 여는 방식으로 바꿨습니다.
- `전체 화면`을 누르면 제목과 주변 영역을 숨겨 모니터에 맞춰 확대합니다. 화면 비율은 16:9로 유지하고, 다른 비율의 모니터에서는 여백을 둡니다.
- 전체 화면에서도 언어·음향·조작 안내를 이용할 수 있습니다. 안내를 열거나 전체 화면을 나가면 게임을 멈춥니다. 안내를 닫은 뒤 계속하기를 눌러 재개합니다.
- `Esc`는 열린 안내를 먼저 닫고, 다음에는 전체 화면을 나갑니다. 일반 화면에서는 기존처럼 일시정지/계속하기입니다.
- 전체 화면을 허용하지 않는 브라우저에서는 브라우저 창 안에서 확대합니다.
- 게임 속 이동 범위, 난이도, 전투 수치, 순위와 선택형 기록 수집은 그대로입니다. 새 플레이 기록에는 `v17`을 저장해 이전 버전과 구분합니다.

이번 변경은 저장소 병합까지 진행하며, 위 공개 링크는 별도 배포 전까지 v16입니다. 화면 크기 요청을 반영한 변경으로, 이용자 만족도나 완료율 개선이 측정됐다는 의미는 아닙니다.

## v16 업데이트 · 선택형 플레이 기록

게임 위의 ‘플레이 기록 분석에 참여’를 선택한 다음 새 게임을 시작하면 난이도, 스테이지 진행, 보스전, 사망·재도전, 필살기 준비·사용과 게임 결과를 기록합니다. 기본값은 미동의이며, 동의하지 않아도 플레이할 수 있습니다. v15의 전투 수치는 그대로입니다.

- 게임마다 새 임의 번호를 사용하며 분석 표에 이름·이메일·IP·전체 유입 주소를 저장하지 않습니다. 순위표와 호스팅 접속 기록은 별개입니다.
- 참여를 해제하면 이후 수집을 멈춥니다. 이미 전송된 기록은 보관 정책에 따릅니다.
- 운영자만 원본을 조회하고 CSV로 내보냅니다. 테스트 자료는 기본 분석에서 제외합니다.
- 결과를 확인하지 못한 플레이는 실패로 단정하지 않습니다. 최근 90일을 분석 대상으로 하며, 오래된 원본은 다음 수집 요청 때 정리합니다.

[수집 항목·분석 한계·운영자 내보내기 안내](odysseus-lost-worlds/TELEMETRY-v16.md)

자동 검사 109개와 테스트 기록의 실제 서버 저장을 확인했습니다. 브라우저 시작 검사와 자동 전투 시뮬레이션을 구분했으며, 실제 이용자 분석 성과를 뜻하지는 않습니다.

## v15 업데이트

### 네 가지 여정 난이도

| 난이도 | 일반 적 체력 / 공격력 | 보스 체력 / 공격력 |
| --- | --- | --- |
| 이타카의 길 · 쉬움 | 85% / 85% | 85% / 85% |
| 에게해의 항해 · 보통 | 100% / 100% | 100% / 100% |
| 신들의 시련 · 어려움 | 115% / 115% | 120% / 115% |
| 포세이돈의 분노 · 최상 | 130% / 130% | 135% / 130% |

비율은 v14의 능력치를 기준으로 합니다. 체력과 피해량은 정수로 반올림합니다. 기본 난이도는 **에게해의 항해**이며, 진행 중인 게임의 난이도는 바뀌지 않습니다. 새로 선택한 난이도는 새 게임을 시작할 때 적용됩니다.

### 두 칸 필살기 게이지

에너지는 최대 **2칸**까지 모입니다. Q·W·E는 각각 1칸, R 제우스는 2칸이 필요하며 사용한 만큼만 차감됩니다.

### 이전 업데이트

- **v14:** 보스 체력과 공격력을 약 5% 낮췄습니다. v15에서도 이 조정을 유지합니다.
- **v13:** 목숨 3개와 보스전 무작위 회복 구역을 추가했습니다. 목숨이 남아 있으면 쓰러진 전투에서 다시 도전할 수 있습니다.

## AI와 함께 만든 과정

만들고 싶은 게임과 수정할 내용을 사용자가 정하고, ChatGPT·Codex를 활용해 기획 정리, 코드 작성, 오류 확인, 기능 개선과 공개 배포를 진행한 개인 프로젝트입니다.

“목숨을 3개로”, “보스전 중 회복할 공간을”, “난이도를 네 단계로”처럼 플레이 중 느낀 요구를 구체적인 게임 규칙으로 바꾸며 개선했습니다. AI가 작성한 코드는 자동 검사와 브라우저 확인을 통해 점검했으며, 체감 난이도와 재미는 실제 플레이 피드백을 바탕으로 계속 다듬고 있습니다.

```text

  db/ · drizzle/          데이터 저장 구조와 변경 이력
  test-*.cjs / test-*.mjs  자동 검사
  TELEMETRY-v16.md         기록 수집·내보내기 안내
  README.md               게임 폴더 안내
```

저장소를 내려받은 뒤 폴더 구성을 그대로 유지하고 `odysseus-lost-worlds/index.html`을 컴퓨터 브라우저에서 엽니다. 게임 화면을 실행하기 위해 npm이나 패키지를 설치할 필요는 없습니다. HTML, CSS, JavaScript와 Canvas로 동작합니다.

이 저장소에는 브라우저 게임과 서버 소스가 함께 있습니다. **온라인 순위·조회수·플레이 기록은 공개 사이트의 서버와 데이터베이스가 필요한 기능**이므로, 파일을 직접 열거나 다른 곳에 업로드하는 것만으로 동일하게 제공되지는 않습니다. 실제 이용 기록·CSV·비밀 인증값은 포함하지 않습니다.

개발 검사는 Node.js 24 이상에서 게임 폴더로 이동하여 `node test-game.cjs`, `node --test test-worker.mjs test-telemetry.mjs`, `node build.mjs`로 실행합니다. `.openai/hosting.json`은 기존 Sites 프로젝트의 연결 식별자입니다. 다른 계정에서 배포하려면 자신의 프로젝트와 데이터베이스 연결을 별도로 준비해야 합니다.
